# Self-hosted fonts

Latin-subset variable woff2 files from Google Fonts (fonts.gstatic.com), loaded with `next/font/local`
so builds make no external font requests. Licenses: SIL Open Font License 1.1 (see the `OFL-*.txt` files).

| File | Family | Weights used |
|---|---|---|
| DMSans-latin-var.woff2 | DM Sans | 400–700 |
| Syne-latin-var.woff2 | Syne | 600–800 |
| RobotoMono-latin-var.woff2 | Roboto Mono | 400–700 |
| Inter-latin-var.woff2 | Inter | 100–900 |
