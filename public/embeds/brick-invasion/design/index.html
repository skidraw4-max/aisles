  • 스타일 = 치비·카와이, 큰 눈, 볼터치, 두꺼운 아웃라인
  • 플레이어 = 통통 금색 포대 마스코트 + 웃는 플라즈마 탄

  • UI = 말랑한 라운드 버튼, 알약형 HUD, 부드러운 파스텔 네온
